# Toso media

Public images and videos for Toso's social posts (@heytoso). Buffer reads files from here by link.

- `brand/` logo and profile picture. Permanent.
- `social/` headers and highlight covers. Permanent.
- `queue/` media scheduled but not yet posted. Named `YYYY-MM-slug.ext`.
- `kit/` the post renderer: `node kit/render.mjs spec.json` turns a short JSON spec into on-brand PNGs (Manrope, Silkscreen, TOSO., one violet square).
- `posted/` empty. Posted media is deleted from `queue/` each month; the platforms keep their own copies.

Rules: media only. No code, config, keys or unreleased plans. Everything here is public.
